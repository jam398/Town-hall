### 4. Debugging & Problem-Solving (70% AI-assisted)

**Common Issues Resolved with AI:**

#### Issue 1: Date Formatting Bug
**Problem:** Event webhook was sending `dateTime` as ISO string, but Discord needed separate date and time.

**AI Usage (Claude):**
```typescript
// AI-suggested solution
const eventDate = new Date(event.dateTime);
const dateStr = eventDate.toLocaleDateString('en-US', { 
  year: 'numeric', month: 'long', day: 'numeric' 
}); // "December 20, 2025"
const timeStr = eventDate.toLocaleTimeString('en-US', { 
  hour: 'numeric', minute: '2-digit', hour12: true 
}); // "6:00 PM"
```

**Human Refinement:** Verified locale settings, tested edge cases

#### Issue 2: Slug Extraction Error
**Problem:** `event.slug` was an object, needed `event.slug.current`

**AI Usage (Claude):**
- Identified the issue by analyzing Sanity schema structure
- Suggested accessing `.current` property
- Provided fix pattern for all slug references

#### Issue 3: HubSpot 409 Conflict
**Problem:** HubSpot API returned 409 when contact already exists

**AI Usage (Claude):**
```typescript
// AI-suggested error handling
if (response.status === 409) {
  // Contact already exists, update instead
  const existingId = await this.findContactByEmail(email);
  return this.updateContact(existingId, data);
}
```

**Human Refinement:** Added logging, tested update flow

#### Issue 4: n8n Webhook Test Mode Timeout
**Problem:** Test webhooks expired after one use

**AI Usage (Claude):**
- Explained test vs production webhook behavior
- Suggested clicking "Listen for Test Event" before each curl test
- Provided correct curl command format
